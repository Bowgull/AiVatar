SHEET 28 - AANG'S PAGE

The desk window becomes one page inside the browser, opened only when you call it (no permanent tab or trail). The research behind these: browsers keep things you USE (history, downloads) apart from SETTINGS; a list down the side beats a row of tabs once there are more than 5 or 6 sections (Aang has 8); and extra copies of the same button cost attention, so each way in should serve a different moment. Your games agree: one menu, one key, it always opens in the same place, settings last.

THE WAYS IN (SAME FOR ALL THREE OPTIONS)

1. Aang's key in the top barHis face, beside the ... key (look at the bars below). The one button anyone can find. Already open? It jumps to it.
2. Ask him"What do you know about me?", "show my jobs": opens the page at that section.
3. Links from where you are"Saved to memory" in the bubble opens that memory; a job alert opens that job; "quota low" opens the meter.
4. A shortcut, for youCtrl+Shift+A (say if you want a different key). Nobody else needs to know it.
Not doing: copiesNo second button in a sidebar, no menu item copying the key, no tray entry on top of the key, no permanent tab.

A - THE PAUSE MENU (RECOMMENDED)

One page with a dark-wood list down the side, like Stardew's menu standing up. The things you use first, then a line, then the switches last. It always opens on What I Know; Ctrl+Page Up / Page Down step through the sections like Z and R on the N64. Aang's settings live here; the browser's Settings page gets one row pointing here, and his settings one row pointing back. Room to grow without getting crowded.
