1EVERY KIND OF ASK, SORTED

Everything that stops and waits for you, from Aang's own code and from Claude's sessions, sorted into the three kinds. The ones that are just news with a key on them stay plain.

QUESTION

  • Aang's own choices (pick one, Something else)
  • "Is this true?" (a fact to remember)
  • A Claude session's question (one or several, with BEST)
  • Send to Aang: Ask about it / Keep as a note (sheet 62, not built yet)

NEEDS YOUR OK

  • Aang asking first (open, delete, run)
  • This cannot be undone (the hold lever)
  • An email to send (the letter itself)
  • Costs more (use Opus for this one?)
  • Back up your memory now?
  • A Claude session wants to use a tool (Allow / Always / No)

PLAN TO OK

  • Aang's plan (here is what I will do, Go)
  • A Claude session's plan (Go / Change it)
  • Samara's plan card (sites, steps, Go / Change / Not now)

NO TAG

  • Plain news and replies
  • Time's up, a reminder (Got it / 5 more)
  • Aang's brain restarting

3THREE WAYS

The same six asks in each. What all three share: who is asking sits beside the kind (AANG, or CLAUDE · WAYMARK with Claude's mark); an OK shows exactly what you are allowing as a quoted line (the command, the files, the site); OK keys say Allow (blue) and Not this time; Aang's own choices get the same answer boxes Claude's questions already have.

?WHAT EACH PART DOES

The kind tagQUESTION (lavender, ?): Aang or Claude wants an answer. NEEDS YOUR OK (blue, key): nothing happens until you allow it. PLAN TO OK (cream, scroll): a list of steps waiting for Go. Who is askingAANG, or CLAUDE · the project's name with Claude's mark. Today a Claude ask only says the project in tiny brown letters. Exactly thisOn an OK only: the command, the files or the site, word for word, in quotes. Today it hides behind "See the exact command" or "Claude's words". Allow / Not this timeThe OK keys. Allow is the kind's blue, not the usual yellow, so it never looks like an answer to a question. Always and No, and... stay where Claude offers them. Answer boxesAang's own choices get the boxed rows Claude's questions already have (today they are plain lines of text). No tagPlain news, a timer, a reminder: they never wait on you, so they stay untagged.
How these were made
  • Every picture is Aang's real bubble page (bubble.html, look B, the slim wood rim), fed each ask the way the app feeds it, off screen. Aang is his own idle frame at real size.
  • Today is untouched. A, B and C add only the tag, the quoted line, the new key words and the colour (B tints the rim's own wood). The projects, files and commands are made up.
  • Send to Aang is sheet 62's drawing (not built yet). The hold lever and the email letter follow the NEEDS YOUR OK look; not drawn here.
