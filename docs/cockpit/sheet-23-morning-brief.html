WHAT THE BRIEF NO LONGER SHOWS

This morning's brief listed these under "Needs a reply". None of them needs you, so they are gone:
Pop's Cannabis: Surprise! A Birthday Gift Inside (a promo)
Nokia API Hub: 85% of your quota (an automatic alert)
JobOffer.com: New Top Jobs Alert (a newsletter; real matches show as "new job matches")
Google: Security alert (automatic)

How it decides: code first drops no-reply senders, newsletters, promos and alerts. Then Aang (Haiku, a sliver of your week) reads what is left and keeps only mail where a real person is waiting on you, with one line saying what they want.
