SHEET 78 - THE ADDRESS BAR KEY

Today's key is drawn on a 7-pixel square: there's no room for a ring, a shaft and teeth, so it comes out squashed. Three keys with room to breathe, each with a padlock built the same way. Each row: the key dim (normal), lit (a login is ready / just unlocked), and its padlock (Bitwarden needs your PIN), at true size in the real bar, then enlarged.
